# C Learning Files

This folder contains the C programs I created while learning C through tutorials and hands-on practice.

These files are mostly small exercises and experiments used to understand different C concepts. They are not intended to be polished projects.

## Topics Practiced

The files cover concepts such as:

* Variables and data types
* Input and output
* Operators
* Conditional statements
* `if`, `else if`, and `else`
* `switch` statements
* `for`, `while`, and `do while` loops
* Functions
* Arrays
* Strings
* Pointers
* Structures
* Header files
* Multiple-file programs

## Purpose

The purpose of this folder is to document my learning process and keep the code I wrote while actively learning C.

Some programs may be very simple, repetitive, or incomplete. That's intentional — they represent individual steps in the learning process rather than finished software.

## Note

As I continue learning C, more practice files and projects will be added separately.
